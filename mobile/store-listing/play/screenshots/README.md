# Play Store screenshots (Android)

Capture source: PriceScout Android app running on a physical phone.

## Output requirements
- PNG format
- `1080x1920` (portrait)
- Keep status bar visible and avoid heavy notification clutter
- Save files with exact names below

## Required files
1. `01-scan.png`
   - Camera view with reticle overlay
   - Item centered and clearly visible

2. `02-verdict.png`
   - Verdict/result card visible
   - Show suggested tag price, comp median, and confidence/sample info

3. `03-tag-list.png`
   - Saved scan/tag list with 4-5 entries visible
   - Demonstrates shared crew workflow history

4. `04-pricing.png`
   - Pricing screen with tier cards visible
   - Include Founders Lifetime card area if possible

5. `05-settings.png`
   - About/settings screen
   - Show account/app context for trust

## Operator capture steps
1. Open PriceScout on Android and log in if needed.
2. Use Quick Settings > Screenshot for each required screen.
3. Transfer images to repo and rename to required filenames.
4. Place final images in this folder.

## Optional quality pass
- Crop only if needed to keep 1080x1920.
- Ensure text is crisp and no sensitive personal data is visible.
